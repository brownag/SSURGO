## Notes

**Code quality observations:**
- Error handling via tryCatch wraps errors in `structure(..., class = "try-error")`, then checks `inherits(results, "try-error")`. This logic should work if sapply preserves the structure, but edge case: if all downloads succeed, results is a clean character vector; if some fail, it's mixed types. The inherits() check on a vector may not work as intended in R (typically operates on single objects). **Risk: failed downloads might not be detected correctly.**
